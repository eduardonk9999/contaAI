# ContAI

Copiloto financeiro com controle de estoque para lojistas, vendedores autônomos e pequenos comerciantes.

## Organização do projeto

```text
contaai/
├── app/        # Aplicativo Flutter
├── backend/    # API, banco de dados e integrações
└── docs/       # Produto, regras de negócio, API e monetização
```

## Documentos principais

- [`docs/BUSINESS-RULES.md`](docs/BUSINESS-RULES.md): visão do produto e regras originais.
- [`docs/BACKEND-SPEC.md`](docs/BACKEND-SPEC.md): contrato que será compartilhado entre API e Flutter.
- [`docs/DATA-MODEL.md`](docs/DATA-MODEL.md): entidades, relacionamentos e corte do banco para o MVP.
- [`docs/BUSINESS-MODEL.md`](docs/BUSINESS-MODEL.md): modelo de receita, planos e argumentos para apresentação.
- [`docs/CODEX-PROMPT.md`](docs/CODEX-PROMPT.md): prompt inicial do projeto, preservado como referência histórica.

## Estado atual

O projeto está na fase de definição e preparação. Ainda não há implementação do backend ou do aplicativo.
